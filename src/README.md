Pgta 1. ¿Desde dónde es posible acceder a la variable "time"?

Respuesta: 3)myUtilities package, ya que time no tiene ningun modificador, asi que 
cualquier clase dentro del package puede acceder a la variable.

Pgta 2. ¿Quiénes pueden acceder al atributo "day"?

Respuesta: La variable "day" fue modificada para ser "public", asi que cualquier
clase de cualquier paquete puede acceder al atributo.

es el mas restrictivo.
